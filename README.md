# 열맞춤 10

광고 없는 숫자 짝 맞추기 퍼즐. 같은 숫자나 합이 10인 두 칸을 지워 판을 비우면 됩니다.

- 가로·세로·대각선으로 이어진 칸, 줄 끝 → 다음 줄 첫 칸도 OK (지운 칸은 건너뜀)
- 줄이 다 비면 삭제, 짝이 없으면 "열 추가"
- 난이도 4단계(쉬움/중간/어려움/숙련), 난이도마다 색 테마와 최고 기록
- 미니멀 효과음(끄기 가능), 틀리면 약한 진동(지원 기기만)
- 자동 저장(브라우저 localStorage), 오프라인 동작(PWA)

## 실행
`index.html`을 브라우저로 열면 바로 플레이됩니다. GitHub Pages 등 https로 올리면
휴대폰에서 "홈 화면에 추가"로 앱처럼 설치할 수 있습니다.
